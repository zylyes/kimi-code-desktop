# 联系与反馈

遇到问题、有功能建议，或想直接和团队交流？先看能否自助解决，若仍需要帮助，再通过下方任一渠道联系我们。

## 反馈前的自助排查

[常见问题](kimi-code/faq.md)收录了高频疑问，[错误参考](kimi-code/error-reference.md)解释了常见的服务端报错，遇到问题可以先到这两处查一查。

也可以先自查几项，不少能就地解决：

- CLI 是否为最新版本（运行 `kimi --version` 查看，必要时更新）
- 网络能否连上 Kimi 服务：公司网络或代理有可能拦截 `api.kimi.com`
- 是否已登录、API Key 是否有效
- 当前工作目录与文件读写权限是否正常

## 反馈渠道

若仍未解决，或想提交建议、直接与团队交流，可通过以下渠道联系我们。

### 加入飞书交流群

用飞书扫描下方二维码加入 Kimi Code 用户群，与团队和其他用户实时交流、获取帮助。

![Kimi Code 用户群飞书二维码]

### 在 CLI 中直接反馈（推荐）

在 Kimi Code CLI 交互界面中输入 `/feedback`，按提示选择随反馈一起上传的内容：

- **No attachment**：仅提交文字反馈
- **Logs only**：附带本次会话的 wire events 与诊断日志；**建议至少选这项**，方便我们定位问题
- **Logs + codebase**：进一步附带代码库以做深入诊断；`.env`、配置文件、密钥等敏感文件会自动排除，附件仅用于诊断、绝不外泄

提交成功后，CLI 会显示本次的 `Session` 与 `Feedback ID`。到上方的飞书交流群把这两个 ID 发出来即可跟进。

### GitHub Issues

前往 Kimi Code CLI 仓库检索已有问题或新建 issue：

- [https://github.com/MoonshotAI/kimi-code/issues](https://github.com/MoonshotAI/kimi-code/issues)

### 邮件

发送邮件至 [code@moonshot.ai](mailto:code@moonshot.ai)。为便于我们快速定位，建议在邮件中附上：

- 问题描述
- 复现步骤
- 环境信息（可运行 `kimi --version` 获取）
- 相关错误日志——在 CLI 中运行 `/export-debug-zip`（或命令行 `kimi export`）导出调试 ZIP，已自动打包诊断日志，作为附件发来即可

## 账号申诉

若账号被误封或需投诉举报，请发送邮件至 [support@moonshot.cn](mailto:support@moonshot.cn)，并附上账号 ID、发生时间与相关情况说明。
