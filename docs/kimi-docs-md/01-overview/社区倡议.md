# Kimi Code 社区倡议

Kimi Code 致力于为全球用户提供智能、高效的 AI 编程服务，用模型能力的持续跃迁、Agent产品力的极致打磨、Token Plan的范式革新，缩短人类想象到现实的路径，让通用agent普惠每个有想法的个体。为保证每位Kimi Code用户拥有更好的体验，我们提出以下倡议。

## 适用范围

Kimi Code 订阅仅限交互式使用，我们兼容主流编程工具与 Agent 框架（Kimi CLI、VS Code、Claude Code、OpenCode、OpenClaw 等），你可以在自己习惯的工具里自由调用 Kimi Code 的 AI 能力。如有企业级集成、商业化服务或其他开放平台相关需求，也可前往 [Kimi 开放平台](https://platform.moonshot.cn) 了解更多合作方案。

## ✧ 我们有必要提示的使用规范

为了让每个人都能持续获得稳定的模型服务，有一些使用规范我们需要大家一起遵守。

#### 不以商业化为目的转售账号或 API 访问权限

账号是你和 Kimi Code 之间的连接，转让给他人使用也会让你自己的数据和使用记录处于风险中。

#### 不将 Kimi Code 的能力以任何形式二次分售

用 Kimi Code 来辅助自己的工作完全没问题，但把它包装成服务再卖给别人，绕过平台的定价和服务体系，对其他正常用户也不公平。

#### 不伪造或篡改客户端身份信息

客户端身份信息是平台识别请求来源、保障服务质量与安全的重要依据，伪造 User-Agent 或使用高风险的 Agent 不利于平台维护整体服务的稳定性。

#### 不进行非个人交互式使用

Kimi Code 订阅仅限个人交互式使用场景。通过脚本批量执行、数据标注等非交互式方式使用，超出了正常使用范畴。

如果出现了不符合上述规范的使用方式，我们会先评估情况，再根据情节进行**暂停访问**等处理。你会收到 `Access terminated` 报错，详情请见[错误参考文档](kimi-code/error-reference.html#账号访问终止)。相应地，若用户通过非官方渠道获取服务（如账号转售、第三方代购等），一经核实可能面临封号处理，且由此产生的损失需由用户**自行承担**。

## 常见问题

**Q1: 我是重度用户，每天高强度使用，会被误封吗？**

不会。风控识别会考虑多种特征，对于 IP 地址、对话状态等使用指标正常的重度用户通常不会触发处置。

**Q2：我用 VPN 或公司代理访问，会被误封吗？**

通过代理访问 Kimi（正向代理）没问题；把自己的账号给别人转发（反向代理），属于违规。

**Q3: 我同时在多个设备或工具上使用 Kimi Code，会被误封吗？**

不会。开发者在不同设备（如工作电脑、个人笔记本）或使用不同编程工具（Kimi CLI、VS Code、Claude Code）之间切换，属于完全正常的使用模式。只要不刻意篡改客户端身份信息就不会被误封。
