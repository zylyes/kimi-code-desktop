# 会员权益

## 概述

Kimi Code 是 [Kimi 会员权益](https://www.kimi.com/membership/pricing?from=kfc_docs_membership) 中面向开发者的智能编程服务，随 Kimi 会员订阅一同提供，与 Kimi 会员共享同一套额度。CLI、VS Code 及第三方工具发起的请求，均计入该额度。

订阅档位与价格详见 [Kimi 会员权益页](https://www.kimi.com/membership/pricing?from=kfc_docs_membership)。

## 额度与限制

Kimi Code 的额度以订阅日为起点**每 7 天自动刷新**，未用完不累积。除周额度外，还有**每 5 小时的滚动频率窗口**——即使总量充足，短时间请求过多也会触发限流，等窗口滚动后自动恢复。

所有登录设备和 API Key 共享同一套配额；超过 30 天未活跃的设备会自动解绑，重新 `/login` 即可恢复。登录 [Kimi Code 控制台](https://www.kimi.com/code/console) 可随时查看剩余额度与频限状态、管理 API Key 和登录设备。

> Kimi Code 与 Kimi 会员计划共享额度：如 Kimi 会员月总额度达到上限，Kimi Code 额度会冻结，需等待月额度重置或升级订阅。月额度消耗可在 [订阅](https://www.kimi.com/membership/subscription) 页查看。

## 加油包

订阅额度用尽后，可用加油包（Extra Usage）余额继续发起请求，不必等待刷新。仅订阅会员可开启，且**网页端 Kimi 与 Kimi Code 共享同一份加油包额度**。完整条款见 [加油包充值协议](https://www.kimi.com/user/agreement/extra-usage-rules-cn)。

![额度加油包]

### 充值入口

- **从主站充值**：进入 Kimi [订阅页面](https://www.kimi.com/membership/subscription?tab=quota)，滚动至页面底部的「额度加油包」模块 → 选择充值金额 → 完成支付即可。
- **从 Kimi Code 控制台充值**：当你的**周额度或 5 小时额度任意一项消耗超过 80%** 时，进度条卡片会出现【加油包购买】按钮，点击即可跳转到 Kimi 订阅页完成购买。

![Kimi Code 控制台的额度加油包入口]

### 开启与管理

打开「额度加油包」开关后，当订阅额度用尽时，系统会自动从加油包余额中扣减。点击模块的「设置」可开启**每月消费上限**、设定本月最多可花费的金额；进度条则实时显示本月加油包的消耗情况。

### 计费与规则

- **计费**：按实际用量扣费——读取与生成的内容越多、任务越复杂，花费越高；余额以人民币显示，费率以平台展示为准。加油包价格近似于 [Kimi 开放平台](https://platform.kimi.com) 的官方 API 价格；用量较大时，升级订阅通常更划算。
- **消耗优先级**：先扣订阅等限时额度，**加油包最后扣**，作为兜底补充。开启后即使订阅额度被打满，也能无缝消耗加油包余额，任务不中断、不报错。
- **限额控制**：可在设置中开启「每月消费上限」，为加油包设定本月最多可花费的金额；不开启则不限额。
- **有效期与叠加**：余额不过期、可叠加；订阅失效后余额仍可继续消费，但失效期间无法再充值，需重新开通订阅后才能充值。
- **退款**：一般不可退款、转让或兑现。

> 计费示例（引自官方示例，仅供感受量级，实际以平台为准）：一次简单请求（如「推荐一首摇滚歌曲」）约 **0.03 元**；一次复杂的多步任务（如「规划一周成都到川西的自驾行程」）约 **1.6 元**。

> 充值限制：单次最低 25 RMB，每日最多 10 次、累计 3,000 RMB，余额上限 10,000 RMB。

### 查询用量

- **Kimi 网页 / App**：设置 → 订阅和发票 → [我的额度](https://www.kimi.com/membership/subscription?tab=quota)。
- **Kimi Code 控制台**：**开启加油包后**，登录 [控制台](https://www.kimi.com/code/console) 即可查看余额与用量。
- **Kimi Code CLI**：在命令行中输入 `/usage` 直接查询。

## 常见问题

- **网页端 Kimi 和 Kimi Code 的加油包是同一个钱包吗？** 是的。加油包额度在 Kimi 与 Kimi Code 之间共享——充值一次，两端通用；「我的额度」里充值的加油包与 Kimi Code 控制台的加油包也是同一个。
- **加油包和订阅额度谁先扣？** 先扣订阅等限时额度，加油包在所有限时额度耗尽后才作为兜底扣除。
- **达到月 / 周 / 小时额度上限，或会话中被限流时，还能继续吗？** 能。开启加油包后不受订阅限额影响，任意额度触顶都会无缝切到加油包余额，任务不中断、不报错，且只扣加油包余额、不影响会员额度刷新。
- **加油包怎么计费？和同价位的订阅、开放平台 API 相比如何？** 计费取决于请求的输入 / 输出量与 cache 命中率；加油包单价近似 [Kimi 开放平台](https://platform.kimi.com) 的官方 API，用量较大时升级订阅通常更划算。
- **没用完的余额能留到下个月、能叠加吗？** 能。余额制、不过期、可叠加；订阅失效后余额仍可消费，但失效期间无法充值，需重新开通订阅后再充。
- **余额快用尽时（如充了 25 元），会保证当前请求跑完吗？** 会保证「最后一次模型调用」即使计费超限也完成，但不保证整个任务一定跑完。
- **加油包支持企业版吗？** 暂不支持。
- **注销账户后余额会退回吗？** 请邮件联系 [membership@moonshot.cn](mailto:membership@moonshot.cn) 申请退款。
