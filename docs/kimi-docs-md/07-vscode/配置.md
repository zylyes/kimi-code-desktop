# 配置

> **⚠️ VS Code 插件适配中**
>
>

Kimi Code for VS Code 目前仅对旧版 Python CLI 用户开放新增安装。已安装插件的老用户升级新版 CLI 后仍可继续使用，其他 TS 版本 CLI 用户暂不支持安装。

在 VS Code 设置的 "Kimi" 部分进行配置（也可通过操作菜单 → **General Config** 打开）。

### 操作审批

<table><thead><tr><th>设置项</th><th>默认值</th><th>说明</th></tr></thead><tbody><tr><td>`kimi.yoloMode`</td><td>`false`</td><td>自动批准所有工具调用。适用于信任工作流程且追求效率的场景</td></tr></tbody></table>

### 文件与编辑器

<table><thead><tr><th>设置项</th><th>默认值</th><th>说明</th></tr></thead><tbody><tr><td>`kimi.autosave`</td><td>`true`</td><td>Kimi 读写文件前自动保存</td></tr><tr><td>`kimi.editorContext`</td><td>`never`</td><td>控制何时共享当前编辑器的文件和光标位置（`never` / `onConversationStart` / `onFileChange`）</td></tr></tbody></table>

### 输入与快捷键

<table><thead><tr><th>设置项</th><th>默认值</th><th>说明</th></tr></thead><tbody><tr><td>`kimi.useCtrlEnterToSend`</td><td>`false`</td><td>使用 Ctrl/Cmd+Enter 发送消息</td></tr><tr><td>`kimi.enableNewConversationShortcut`</td><td>`false`</td><td>启用 Cmd/Ctrl+N 新建对话快捷键（启用后将占用系统默认的"新建文件"快捷键）</td></tr></tbody></table>

### 模型与推理

<table><thead><tr><th>设置项</th><th>默认值</th><th>说明</th></tr></thead><tbody><tr><td>`kimi.alwaysExpandThinking`</td><td>`false`</td><td>默认展开思考/推理过程</td></tr></tbody></table>

### 高级

<table><thead><tr><th>设置项</th><th>默认值</th><th>说明</th></tr></thead><tbody><tr><td>`kimi.executablePath`</td><td>`""`</td><td>自定义 Kimi Code CLI 路径（空值使用内置）</td></tr><tr><td>`kimi.environmentVariables`</td><td>`{}`</td><td>传递给 Kimi Code CLI 的环境变量</td></tr></tbody></table>
