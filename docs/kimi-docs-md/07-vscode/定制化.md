## MCP 服务器

MCP（Model Context Protocol）服务器可为 Kimi 扩展外部工具与服务。通过操作菜单（齿轮图标）→ **MCP Servers** 进行管理。

### 传输类型

支持两种传输类型：

- **stdio**：本地命令行工具，需指定命令、参数和环境变量
- **http**：远程服务，需指定 URL，可选 OAuth
