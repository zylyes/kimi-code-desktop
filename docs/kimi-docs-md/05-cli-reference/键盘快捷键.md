# 键盘快捷键

Kimi Code CLI 的 TUI 交互模式支持一套键盘快捷键。键位按使用场景分为五组：通用输入、模式切换、流式输出期间、工具输出控制、审批面板，以及弹窗浏览。在 TUI 中输入 `/help` 可随时打开内置快捷键清单。

## 通用快捷键

以下键位在输入框中始终可用：

<table><thead><tr><th>快捷键</th><th>功能</th></tr></thead><tbody><tr><td>`Enter`</td><td>提交当前输入</td></tr><tr><td>`Shift-Enter` / `Ctrl-J`</td><td>在输入中插入换行</td></tr><tr><td>`↑` / `↓`</td><td>浏览输入历史</td></tr><tr><td>`Esc`</td><td>关闭弹窗 / 取消补全 / 中断流式输出或上下文压缩</td></tr><tr><td>`Ctrl-C`</td><td>中断当前流式输出，或清空输入框</td></tr><tr><td>`Ctrl-D`</td><td>在输入框为空时退出 Kimi Code CLI</td></tr><tr><td>`Ctrl-T`</td><td>待办列表被截断时，展开或折叠完整列表</td></tr></tbody></table>

**流式输出期间**按 `Ctrl-C` 会立即取消，无需二次确认。

**退出程序**（输入框为空时按 `Ctrl-C`，或按 `Ctrl-D`）使用「双击确认」机制：第一次按下后状态栏会出现提示，再按一次相同的键才真正退出。中途按其他键会清除确认状态。

## 模式切换

<table><thead><tr><th>快捷键</th><th>功能</th></tr></thead><tbody><tr><td>`Shift-Tab`</td><td>切换 Plan 模式</td></tr><tr><td>`!`</td><td>在空输入框中进入 Shell 模式</td></tr></tbody></table>

按 `Shift-Tab` 可开启或关闭 Plan 模式。开启后，Agent 会优先使用只读工具进行研究和规划，并可写入当前计划文件；`Bash` 按当前权限模式和普通规则处理，不会因 Plan 模式额外发起独立审批。单纯切换模式不会创建空计划文件。再次按 `Shift-Tab` 退出 Plan 模式。

在空输入框中键入 `!` 进入 Shell 模式，可直接运行终端命令；命令运行期间按 `Ctrl+B` 可将其转为后台任务。详见[交互与输入](kimi-code-cli/guides/interaction.html#shell-模式)。

## 输入与编辑

<table><thead><tr><th>快捷键</th><th>功能</th></tr></thead><tbody><tr><td>`Ctrl-G`</td><td>在外部编辑器中编辑当前输入</td></tr><tr><td>`Ctrl-V`</td><td>粘贴剪贴板中的图片或视频（Unix / macOS）</td></tr><tr><td>`Alt-V`</td><td>粘贴剪贴板中的图片或视频（Windows）</td></tr><tr><td>`Ctrl--`</td><td>撤销（Undo）</td></tr><tr><td>`Esc` `Esc`</td><td>双击打开撤销选择框（空闲状态下）</td></tr></tbody></table>

按 `Ctrl-G` 会打开外部编辑器，编辑器按以下优先级选择：

- `/editor` 命令配置的编辑器
- `$VISUAL` 环境变量
- `$EDITOR` 环境变量

保存并退出后，编辑内容替换输入框；不保存退出则保持原样。

粘贴图片或视频时，输入框中显示占位符，实际媒体数据在提交时一并发送给模型。优先从系统剪贴板读取；Linux 上会尝试 Wayland 与 X11，WSL 下还会通过 PowerShell 兜底读取 Windows 剪贴板。

## 流式输出期间

流式输出（streaming）期间，输入框依然可以接收输入，并支持以下额外操作：

<table><thead><tr><th>快捷键</th><th>功能</th></tr></thead><tbody><tr><td>`Ctrl-S`</td><td>Steer：将当前输入立即注入正在运行的轮次</td></tr><tr><td>`Esc`</td><td>中断当前流式输出</td></tr><tr><td>`Ctrl-C`</td><td>中断当前流式输出</td></tr></tbody></table>

按 `Ctrl-S` 时，模型会在下一个可中断的时机立刻看到你的消息，无需等待当前轮次结束。

## 工具输出

<table><thead><tr><th>快捷键</th><th>功能</th></tr></thead><tbody><tr><td>`Ctrl-O`</td><td>展开或折叠工具输出和压缩摘要</td></tr></tbody></table>

历史中存在折叠的工具调用结果时，按 `Ctrl-O` 可在折叠和展开之间切换。压缩完成后，同一个快捷键也会在压缩块中显示或隐藏压缩摘要。

## 审批面板

当 Agent 发起需要确认的工具调用时，TUI 会弹出审批面板。详细审批流程见[交互与输入](kimi-code-cli/guides/interaction.html#审批流程)，面板内可用键位如下：

<table><thead><tr><th>快捷键</th><th>功能</th></tr></thead><tbody><tr><td>`↑` / `↓`</td><td>在候选选项之间移动光标</td></tr><tr><td>`Enter`</td><td>确认当前选中的选项</td></tr><tr><td>`1` ~ `9`</td><td>直接选择对应序号的选项</td></tr><tr><td>`Esc` / `Ctrl-C` / `Ctrl-D`</td><td>拒绝当前请求</td></tr><tr><td>`Ctrl-E`</td><td>面板包含 diff 或文件内容预览时，展开或折叠完整内容</td></tr><tr><td>`Ctrl-O`</td><td>切换其他工具输出的折叠状态</td></tr></tbody></table>

需要附带反馈的选项（如「Reject」「Revise」）会在确认后切换到反馈输入态：直接输入反馈文本，按 `Enter` 提交；按 `Esc` 退出反馈输入并回到候选列表。

## 弹窗模式

输入 `/help` 打开帮助面板后，可使用以下键位浏览和关闭面板：

<table><thead><tr><th>快捷键</th><th>功能</th></tr></thead><tbody><tr><td>`↑` / `↓`</td><td>单行滚动</td></tr><tr><td>`PageUp` / `PageDown`</td><td>每次滚动 10 行</td></tr><tr><td>`Esc` / `Enter` / `q` / `Q`</td><td>关闭面板</td></tr></tbody></table>
