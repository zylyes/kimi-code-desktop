K 命令与快捷键速查
输入 / 触发命令补全
Kimi Code TUI 的常用斜杠命令与快捷键，以及本桌面端的窗口快捷键。内容基于官方文档整理。

账户与配置

/login选择账户或平台并登录（OAuth 设备码或 API Key）
/logout清除当前所选账户的登录凭据
/provider打开服务商管理：查看、添加、移除已配置的服务商
/model切换当前会话使用的模型
/settings打开 TUI 内的设置面板
/permission选择权限模式（manual / yolo / auto）
/editor配置 Ctrl-G 调起的外部编辑器
/theme切换 TUI 配色主题

会话管理

/new开启全新会话，丢弃当前上下文
/sessions浏览历史会话，切换或恢复其一
/tasks查看后台任务列表
/fork从当前会话分叉新会话，保留完整对话历史
/title查看或设置当前会话标题
/compact压缩当前对话上下文，释放 token 占用
/undo撤销最近一条或多条输入（可带数量参数）
/reload重载当前会话并应用最新配置，无需重启 CLI
/init分析当前代码库并生成 AGENTS.md
/export-md将当前会话导出为 Markdown 文件
/copy复制最近一条助手回复到剪贴板
/add-dir为当前会话添加额外的工作目录
/web在 Web UI 中打开当前会话

模式控制

/yolo开关 YOLO 模式：跳过常规工具调用审批（可带 on/off）
/auto开关自动权限模式：审批自动处理，不再向用户提问
/plan开关 Plan 计划模式：先研究规划再动手（可带 on/off）
/swarm开关 swarm 并行模式，或直接发起一个并行任务
/goal启动或管理自主目标模式：跨回合持续推进一个目标

信息查询

/help显示快捷键与全部可用命令
/btw开启旁路提问，不影响当前主会话的回合
/usage查看 token 用量、上下文消耗与配额信息
/status查看当前会话运行状态：版本、模型、目录、权限模式等
/mcp列出 MCP 服务器及其连接状态
/plugins打开交互式插件管理器
/version显示 Kimi Code CLI 版本号
/feedback提交反馈，可附诊断日志与代码库上下文

TUI 快捷键

Enter提交当前输入
Shift-Enter / Ctrl-J在输入框中换行
Esc / Ctrl-C中断当前流式输出或上下文压缩
Shift-Tab开关 Plan 模式
!在空输入框中按 ! 进入 shell 模式，直接运行终端命令
Ctrl-SSteer：把当前输入直接注入正在进行的回合
Ctrl-O展开或折叠工具输出与压缩摘要
Ctrl-T展开或收起被截断的 todo 列表
Ctrl-G在外部编辑器中编辑当前输入

桌面端快捷键

Ctrl+Shift+Space显示 / 隐藏主窗口（全局热键，任意界面可用）
Ctrl+Shift+S打开会话启动器
Ctrl+Shift+N新建会话
Ctrl+L手动输入地址
Ctrl+R重新加载窗口
Ctrl+T窗口置顶开关
F1打开本帮助
